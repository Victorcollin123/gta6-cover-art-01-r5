Leonida Nights — a GTA 6 loading-screen cover studio: turn a photo and a caption into Vice City neon-sunset cover art, offline in the browser, exported as PNG. Pick a photo, place it in the hero frame, choose a cover style (Loading Screen, Magazine, Wanted Poster) and a colour grade (Sunset, Neon Night, Pastel Vice, Noir), then export at 1080×1080, 1080×1350 or 1920×1080.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
